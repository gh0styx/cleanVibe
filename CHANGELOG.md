# Changelog

All notable changes to CleanVibe will be documented in this file.

The format follows Keep a Changelog style, and this project uses semantic versioning.

## [0.1.0] - 2026-05-23

### Added

- Cursor plugin manifest for CleanVibe.
- Manual commands:
  - `/cleanvibe`
  - `/cleanvibe-diff`
  - `/cleanvibe-index`
  - `/cleanvibe-react`
  - `/cleanvibe-next`
- Local MCP server with CleanVibe audit tools.
- TypeScript/JavaScript project index with external cache.
- Diff audit with untracked source-file support.
- Whole-project audit for duplicate exports, boundary drift, complexity hotspots, and shortcut markers.
- React and Next.js detector pack command surfaces.
- Markdown output designed for Cursor chat instead of raw JSON.
